# Task Management Dashboard

## About

This is a task management application built using React and TypeScript.

It helps users manage their daily tasks.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Search tasks
- Filter tasks
- Sort tasks
- View task statistics
- Save tasks using LocalStorage
- Import and export tasks
- Light and dark mode
- Responsive design

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- HTML
- CSS

## How to Run

Install packages:

bash
npm install


Start the application:

bash
npm run dev
